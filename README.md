# AI-Driven Casting Quality System

## Project Overview

The AI-Driven Casting Quality System is a machine-learning-based
engineering decision-support system for analyzing casting process
parameters and predicting quality-related outcomes.

The system will analyze available casting process data and provide:

- Casting defect prediction
- Porosity prediction
- Yield prediction
- Explainable AI-based parameter analysis
- Process anomaly detection
- Quality analysis and contributing-factor support
- What-if scenario analysis
- Model-based scenario exploration
- Interactive dashboard visualization

## Project Scope

This project is designed as an engineering decision-support system.

It does not automatically control a casting process. The predictions,
analysis, and recommendations generated by the system are intended to
support engineering investigation and decision-making.
